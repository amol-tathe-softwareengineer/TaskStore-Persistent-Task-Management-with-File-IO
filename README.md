# TaskStore: Persistent Task Management with File I/O

## Overview
TaskStore is a Python-based CRUD application designed to manage tasks efficiently with persistent file storage using File I/O operations.

The application allows users to create, read, update, and delete tasks while ensuring data durability through text file storage.

## Features
- Add New Tasks
- View Existing Tasks
- Update Tasks
- Delete Tasks
- Persistent File Storage
- Error Handling for File Operations

## Technologies Used
- Python
- File I/O
- Exception Handling

## Objective
To implement persistent task storage and improve data management functionality using text file handling techniques.

## Key Learning Outcomes
- CRUD Operations
- File Handling
- Data Persistence
- Exception Handling
- Problem Solving
